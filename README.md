# Proyecto de Obra Nueva: 46 Viviendas Colectivas

Este repositorio contiene una sencilla página web estática para presentar un proyecto de obra nueva compuesto por 46 viviendas colectivas.

## Estructura

- `web/index.html`: página principal con la descripción del proyecto.
- `web/style.css`: estilos básicos para la página.

## Cómo visualizar la página

Basta con abrir el archivo `web/index.html` en un navegador web para ver el contenido.
